## 질문 1 — "임상 소견과 함께 판단이 필요합니다"의 처리 (가장 중요)

A) 추적 관찰 필요 아님 — 명시적 "권고/재검 필요"만 필요로 판별 (가장 보수적, 오탐 최소)

B) 추적 관찰 필요로 포함 — "판단이 필요"도 후속 조치가 필요한 신호로 간주 (미탐 최소, 대신 필요 건수가 크게 늘어남)

C) 별도 표시 — "권고" 계열은 "추적필요", "판단 필요"는 "검토요망" 같은 2차 분류로 구분 표시

X) 기타 (아래 [Answer]: 뒤에 설명해 주세요)

> 🤖 **백엔드 엔지니어 권장**: A) 명시적 권고/재검만 필요로 판별
> **근거**: 각 보기 검토(데이터 기반) — A는 "추가 검사 권고/추적 검사를 권고/재검이 필요/추가 평가 권고"라는 명시적 후속조치 지시만 잡아 오탐이 적고 근거 문장이 뚜렷(US-DOC-2 검증 용이). > **근거**: A는 코어가 "정상 데이터→결과"라는 단일 책임을 유지하고 사용자 메시지 표현(언어/UI)은 각 버전이 담당해 코어 순수성(Q2=A)과 일관. B는 모든 반환 타입에 오류 분기를 섞어 호출부가 매번 성공/실패를 판별해야 하고 코어 API가 지저분해짐. FR-12(명확한 오류 안내)는 UI 계층 책임.
