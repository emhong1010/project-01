# 유닛 의존 매트릭스 (Unit Dependency)

## 의존 관계
| 유닛 | 의존 대상 | 의존 유형 | 사유 |
|---|---|---|---|
| U1 shared-core | (없음) | - | 순수 로직, 임계 경로 |
| U2 v1-web-serverless | U1 | 빌드/런타임 | 파싱·판별·집계 로직 사용 |
| U3 v2-server | U1, U2 | 빌드/런타임 | U1 코어 사용 + U2 UI 컴포넌트 재사용(Q4=B) |

## 의존 그래프
```
        U1 shared-core
         /          \
        v            v
  U2 v1-web      U3 v2-server
        \____________^
         (U3가 U2의 UI 재사용)
```

## 구현/업데이트 전략
- **접근**: 순차 (U1 → U2 → U3)
- **임계 경로**: U1 shared-core (모든 유닛의 기반)
- **조정 지점**:
  - U1의 공개 타입/함수 시그니처가 U2·U3의 계약 → 먼저 안정화.
  - `StatusRepository` 인터페이스는 U2에서 정의하고 U2(local)·U3(server)가 각각 구현.
- **테스트 체크포인트**:
  - U1 완료 시 코어 단위 테스트(파싱·판별·오탐 방지·집계).
  - U2 완료 시 UI 흐름 + localStorage 상태 유지.
  - U3 완료 시 API + 서버 상태 공유, U1 재사용 확인.
- **롤백**: 각 유닛 독립적이라 유닛 단위 되돌리기 용이.
