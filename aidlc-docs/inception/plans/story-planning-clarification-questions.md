# 사용자 스토리 계획 - 명확화 질문

## 감지된 모호성
- 질문 1(페르소나) 답변 = **D(학습자)만 선택**
- 질문 2(분해 방식) 답변 = **C(페르소나 기반)**

페르소나 기반 분해는 의미 있는 페르소나가 여러 개 있을 때 효과적입니다. 또한 요구사항의 실제 동작(과 담당 의사의 상태 표기, 관리자의 과별 모니터링, 운영자의 업로드)은 학습자 페르소나만으로는 표현하기 어렵습니다.

## 명확화 질문 1 — 페르소나 범위
스토리에 등장할 페르소나를 어떻게 잡을까요?

A) 앱의 실제 행위자(진료과 담당 의사=A, 운영/업로드 담당=B, 관리자=C)를 페르소나로 사용하고, 학습자(D)는 "이 도구를 학습·설명 목적으로 살펴보는 관찰자" 페르소나로 함께 포함 — 스토리는 실제 행위자 관점으로 쓰되 학습 맥락을 문서에 반영 (권장)

B) 학습자(D) 하나만 페르소나로 두고, 모든 스토리를 "학습자가 각 역할을 체험/시뮬레이션한다" 관점으로 서술

C) 실제 행위자(A, B, C)만 페르소나로 사용하고 학습자(D)는 제외 (학습 목적은 문서 서두 설명으로만 반영)

X) 기타 (아래 [Answer]: 뒤에 설명해 주세요)

[Answer]: a
