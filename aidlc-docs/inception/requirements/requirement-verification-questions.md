## 질문 13: 페르소나 프록시(Persona Proxy, 부재 역할 자문) 적용 여부
팀(협업 그룹)에 부재하거나 부족한 전문 역할이 있나요? 선택한 각 역할에 대해 AI 페르소나가 해당 도메인 질문에 자문(권장 답변 + 근거 + 신뢰도)을 추가합니다. 최종 답변은 항상 사용자의 몫이며, 페르소나가 대신 답을 채우지 않습니다.

해당하는 항목을 모두 선택해 주세요 (예: "C, F"):

A) 제품 책임자(Product Owner) - 비즈니스/사용자 관점: 목표, 성공 기준, 사용자 시나리오, 스토리 수용 기준

B) 소프트웨어 아키텍트(Software Architect) - 시스템 구조: 컴포넌트 경계, 시스템 분해, 설계 패턴, 위험/변경 영향 평가

C) 백엔드 엔지니어(Backend Engineer) - 서버 측 구현: 도메인 모델, 비즈니스 규칙, 데이터 흐름, 오류 처리, API/저장소 계층

D) 프론트엔드 엔지니어(Frontend Engineer) - 클라이언트 측 구현: UI 구조, 상태 관리, 폼 처리, API 연동

E) DevOps 엔지니어 - 인프라/배포: 클라우드 서비스 선택, 컴퓨팅/스토리지/네트워킹, CI/CD, 배포 전략, 모니터링

F) 보안 엔지니어(Security Engineer) - 보안: 암호화, 인증/인가, 최소 권한, 입력 검증, 컴플라이언스, 위협 모델링

G) QA 엔지니어 - 품질 전략: 단위/통합/E2E/성능/계약 테스트, 수용 기준 테스트 용이성, 엣지 케이스

H) 없음 - 모든 역할이 충분히 대표됨, 페르소나 미적용

X) 기타 (아래 [Answer]: 뒤에 설명해 주세요)

[Answer]: b, c, d
