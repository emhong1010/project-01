# 페르소나 (User Personas)

> 이 프로젝트는 학습·교육 목적을 겸합니다. 스토리는 앱의 실제 행위자(의사·운영자·관리자) 관점으로 작성하되, 학습자(관찰자) 페르소나를 별도로 포함하여 학습 맥락을 반영합니다.

---

## P1. 김민준 — 진료과 담당 의사 / 판독 검토자
- **역할**: 자기 진료과(예: 호흡기내과)로 접수된 판독문 중 추적 관찰이 필요한 건을 확인하고 후속 조치 진행 상태를 표기.
- **목표**: 놓치기 쉬운 추적 관찰 대상을 빠르게 걸러내고, 어떤 건을 처리했는지(대기/진행중/완료) 관리.
- **동기/니즈**: 과별로 필터된 목록, 판별 근거 문장 확인, 간단한 상태 변경.
- **불편/우려**: 규칙 기반 오탐/미탐 — 근거를 직접 확인하고 싶음.
- **기술 숙련도**: 보통 (브라우저 사용에 익숙, 별도 설치는 부담).
- **주요 버전 관심**: V1(개인 검토), V2(과 동료와 상태 공유).

## P2. 이서연 — 데이터 업로드 / 운영 담당자
- **역할**: 판독문 CSV/Excel을 확보해 도구에 업로드하고 전체 현황을 관리.
- **목표**: 올바른 파일을 업로드하고, 파싱/필터가 정상 동작하는지 확인.
- **동기/니즈**: 형식 오류·누락 열에 대한 명확한 피드백, 판독문만 걸러지는 것 확인.
- **불편/우려**: 잘못된 파일이나 열 불일치로 결과가 비거나 왜곡되는 상황.
- **기술 숙련도**: 보통~상.
- **주요 버전 관심**: V1/V2 공통(업로드·파싱).

## P3. 박지훈 — 부서 관리자 / 책임자
- **역할**: 여러 진료과의 추적 관찰 필요 현황과 진행 상태를 한눈에 모니터링.
- **목표**: 과별 추적 관찰 필요 건수와 처리 현황을 요약 대시보드로 파악.
- **동기/니즈**: 전체 요약 + 과별 수치, 과 선택 전환.
- **불편/우려**: 과가 많을 때 한눈에 안 들어오는 화면.
- **기술 숙련도**: 보통.
- **주요 버전 관심**: V2(여러 사용자의 표기가 취합된 공유 현황), V1(단일 스냅샷).

## P4. 한수아 — 학습자 / 교육 대상 (관찰자)
- **역할**: 이 도구의 동작 방식과 코드/폴더 구조를 학습하고, 강의/실습에서 설명을 듣거나 직접 따라해 봄.
- **목표**: "무엇을 왜 이렇게 만들었는지"와 각 기능/구조를 이해.
- **동기/니즈**: 눈에 확 보이는 폴더 구조, 명확한 스토리·근거, V1/V2 차이 이해.
- **불편/우려**: 복잡한 빌드 도구나 흩어진 구조로 학습 흐름이 끊기는 것.
- **기술 숙련도**: 입문~중급 (학습 중).
- **주요 버전 관심**: V1(단순 구조로 학습 시작) → V2(서버 개념 확장 학습).

---

## 페르소나 요약 매핑
| 페르소나 | 핵심 행위 | 주 사용 버전 |
|---|---|---|
| P1 담당 의사 | 추적 관찰 건 확인, 진행 상태 표기 | V1, V2 |
| P2 운영 담당 | 업로드, 파싱/필터 검증 | V1/V2 공통 |
| P3 관리자 | 과별 현황 대시보드 모니터링 | V2(주), V1 |
| P4 학습자 | 동작/구조 학습·설명 | V1 → V2 |
